# GRIB2 数据解析与统计表生成工具

## 项目目的

解析 GRIB2 格式的气象数据文件，提取所有变量记录的元数据与统计信息（min / max / mean），
以**控制台表格、CSV、JSON**三种格式输出可视化的统计报告，重点体现**气压层**等垂直层次信息。

## 技术栈

| 组件 | 版本 | 说明 |
|------|------|------|
| Java | 17 | 运行环境 |
| UCAR CDM (netCDF-Java) | 5.5.3 | GRIB2 数据解析核心引擎 |
| Jackson | 2.15.2 | JSON 序列化 |
| Lombok | 1.18.28 | 简化样板代码 |
| SLF4J + Logback | 2.0.7 / 1.4.8 | 日志框架 |
| JUnit 5 | 5.9.3 | 单元测试 |
| Maven | 3.x | 项目构建 |

核心依赖: `cdm-core`

## 输入

- `data/` 目录下的 GRIB2 格式文件（扩展名: `.grib2`, `.grb2`, `.grb`, `.grib`, `.gb2`, `.g2`）
- GRIB2 文件可来自 NOAA GFS、ECMWF、CMA GRAPES 等数值预报模式

## 输出

输出到 `output/` 目录，每个输入文件生成两份统计报告：

| 格式 | 文件名 | 说明 |
|------|--------|------|
| CSV | `{原文件名}_statistics.csv` | Excel 可直接打开，含 BOM 头 |
| JSON | `{原文件名}_statistics.json` | 结构化元数据，便于程序读取 |

同时控制台打印格式化的 **统计表格**，按气压层降序排列。

## 统计表包含的列

| 列 | 含义 |
|----|------|
| 序号 | 记录在文件中的顺序 |
| 变量名 | 如 Temperature, U-component_of_wind |
| 缩写 | 如 TMP, UGRD, VGRD, HGT, RH |
| 层次类型 | Isobaric surface / Surface / Mean sea level 等 |
| **气压(hPa)** | **等压面气压层值（如 1000, 850, 500, 200）** |
| 预报时效 | 分析场 / +Nh（N 小时预报） |
| 参考时间 | 模式起报时间 |
| 投影 | 网格投影类型，如 Latitude/Longitude |
| NX / NY | 经纬向格点数 |
| 最小值 / 最大值 / 平均值 | 数据统计值 |
| 单位 | 如 K, m/s, %, gpm |
| 描述 | GRIB2 字段描述文本 |

## 如何运行

```bash
# 1. 将 GRIB2 数据文件放入 data/ 目录

# 2. 编译并运行
mvn clean compile exec:java

# 3. 指定自定义数据目录
mvn exec:java "-Dexec.args=/path/to/grib2/files"

# 4. 仅运行测试
mvn test
```

## GRIB2 气压层识别

工具通过 UCAR CDM 库自动识别 GRIB2 中的垂直坐标信息：

- 从 Grid 变量的 **Z 坐标轴**读取层次值和单位
- 若单位为 `hPa` / `Pa` / `mb`，判定为**等压面 (Isobaric surface)**
- 自动换算：`Pa` 单位值 ÷ 100 → hPa
- 非等压面的层次（如 Surface、Mean sea level、Tropopause）单独归类输出

### 常见气压层

模式输出中常见的气压层（hPa）：1000, 975, 950, 925, 900, 850, 800, 750, 700, 650, 600, 550, 500, 450, 400, 350, 300, 250, 200, 150, 100, 70, 50, 30, 20, 10, 5, 1
